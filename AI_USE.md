# AI Use Statement

This document describes how AI tools were used to develop this project, and which parts came from the project members.

**Last updated:** November 6, 2026

## Scope and tools

| Item | Detail |
|---|---|
| Development assistant | Claude Code (Anthropic), running Claude Opus 5.5, used in VS Code |
| Used for | Writing and editing code, documentation, notebook cells; repository maintenance |
| Not used for | Choosing the research question, hypotheses, or experimental design |


**Studied model vs. development tool.** GPT-5.6 Luna (and GPT-6 Luna in the Round 1 pilot) is the **subject** of the experiments. It is called through the OpenAI API by the experiment scripts. It was not used to write the project, and its responses are research data, not AI-generated project content.

## AI-assisted development tasks

- **Experiment code:** the team designed the code structure for the experiments; AI assisted with implementing it (`experiments/`).
- **Results overview notebook:** AI generated the code for the visualizations, following designs from a team member (`results_overview.ipynb`).
- **Documentation:** Markdown files were generated by AI from descriptions written by the team.
- **Written report:** AI was used to polish the language of the team's own writing.

## Representative prompts

**Experiment design and execution**

> "Make the spending cap $1, modify the code such that reaching spending cap is handled by stopping the run, record the current progess, record the partial data to results folder,"

> "Do one dry run of round2_lookup_study, through the fake API client in test_round2_newdata.py, report the result"

**Analysis and visualization**

> "In results_overview, generate a cell that produces a dot plot of whether altering or naming the dataset pulls answers towards the familiar ones. Accuracy on x-axis and round on y-axis."

> "Check the altered vs original value graph. It seems the dots are overlapping, fix it."

**Review and project hygiene**

> "Now do a sanity check for the entire project, do not run any experiments. Provide potential area of caution"

## Human contributions

All research ideas came from the project members:

- **Research question:** whether input format (CSV, JSON, and others) affects whether a model follows the table evidence it is given, including edited values, instead of returning familiar dataset answers.
- **Experimental design:** using record lookup as the primary task; the input formats to compare; edited-value and synthetic controls; the follow-up, selection, and join rounds; and repeating the study on new datasets.
- **Dataset choices:** which datasets to use and why.
- **Constraints:** spending caps, no tools or conversation history in model calls, keeping source rows and credentials out of the public repo, and never overwriting completed runs.
- **Decisions and approvals:** every paid API run was started on explicit human instruction, and every commit and pull request was requested and reviewed by a project member.
- **Interpretation:** the conclusions in the reports are the team's own. AI explanations were treated as aids, not authority.
